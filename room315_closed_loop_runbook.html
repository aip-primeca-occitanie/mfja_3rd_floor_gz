Scope and success rule

Use this page for the current Room 315 simulated system. It does not command physical MFJA equipment. Every movement request remains subject to fresh perception, deterministic presence, planning, device state and supervisor checks.

English requestTerminal 4, after gate
Validated TaskGoalconfirm with yes
Accepted visual stateTerminal 2
PDDL / PlanSys2Terminal 3
Safety-gated motionTerminal 1
Re-observe and verifyterminal status
Exactly one shuttle is supported end to end. Both rail nodes and both camera streams must remain enabled, but a rail may contain zero shuttles. Its timestamped empty-inventory heartbeat keeps deterministic presence ready without creating a phantom shuttle. Scenario 1 is the smallest complete language-model + visual-state-model + PlanSys2 + rail-safety profile.

When a command is successful

Terminal 4 prints a response containing:

  • status: succeeded
  • reason: task_goal_satisfied
  • safe_abort_sent: false

One command at a time

Wait for the terminal result before entering another command. For examples marked fresh launch, restart the scenario first so its listed slot and payload state are true.

“Verified command” in this runbook means that the phrase was checked against the current parser/domain contract and matched to the stated scenario. Runtime still fails closed if a required live input is unavailable; that behavior is intentional.

Use simple, explicit wording for repeatable demonstrations

Move the green shuttle to slot 2.
Move the red shuttle to slot 4.
Move the nearest loaded shuttle on the right rail to slot 3.
Not supported as one atomic natural-language goal: swaps, “move all”, compound agendas, load/unload operations, arbitrary coordinates, requested speeds, deadlines or unrestricted free-form robot programs. The CLI must clarify or reject these requests; it must not approximate them with unrelated motion.

Transport goals always require confirmation. After checking the canonical summary, type yes. Do not use --auto-confirm for operator demonstrations.
