Fiducial detections and identity tracks are privileged metadata for safety, debugging, and evaluation; they are not copied into model_input.

PDDL / PlanSys Scenario Generation

The focused research pipeline uses PDDL with a real PlanSys2 planner as an expert scenario-generation layer. PDDL goals become PlanSys2 symbolic plans, symbolic plans become primitive VLA commands, and those commands are executed only through the existing VLA supervisor. The learned model never sees PDDL facts or plans as input.

Pipeline: PDDL goal/problem to symbolic_plan to primitive commands such as switches, stoppers, shuttle ON/OFF, and DONE. The supervisor safety decoder gates every command, the dataset recorder writes events.jsonl, and the model target remains action_vector.

Path inside an episodeMeaningUse for training?
episode.json Episode summary: ID, task, frame count, event count, success/failure, and safety metrics. No. Use for inspection and bookkeeping.
events.jsonl Main training file. Each JSON line is a decision event: image/language/last_command before the decision, then action and action_vector. Yes. This is the important training file.
data.jsonl Framewise raw replay. It stores detailed frame state for audit and may repeat the same command over multiple frames. No. Do not use as supervised labels.

FieldMeaning
model_input_schema_versionCurrently 3.

model_input.overhead_imagesReferences to camera images allowed for the model.
