\chapter{Repository Source Index}
\label{app:catalog}

This appendix is a package-oriented index of the project's source surface. It
groups implementation modules, launch files, configuration contracts, Gazebo
models, and tests by responsibility so a maintainer can locate the owning file
without searching unrelated repository material. Offline and historical tools
are identified separately from the active ROS 2 runtime. Runtime-created data,
local build output, and external model artifacts are outside this index.

At the documented commit, the repository contains
\RepositoryTrackedFileCount{} tracked files, including
\RepositoryScriptCount{} control-package scripts,
\RepositoryControlTestCount{} control tests,
\RepositoryDescriptionTestCount{} description tests,
\RepositoryModelCount{} Gazebo model directories,
\RepositoryLaunchCount{} launch/support modules,
\RepositoryMessageCount{} messages, and \RepositoryServiceCount{} service.
Use the package- and category-oriented tables below to locate the corresponding
files; use the earlier chapters to interpret their runtime relationships.
