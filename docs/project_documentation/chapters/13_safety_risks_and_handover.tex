\section{Non-Negotiable Deployment Boundary}

\begin{safetybox}[Simulation and research only]
This repository is not a safety-certified controller and is not authorized for
physical machinery. Its current task authorization is Gazebo-only. Do not
connect its command outputs to a real rail, PLC, robot, or gripper without a new
approved hardware architecture, independent risk assessment, trusted sensors,
hard real-time/safety functions, physical commissioning, and organizational
authorization.
\end{safetybox}

The limitation is architectural, not a disclaimer that can be removed after a
successful demo:

\begin{itemize}
  \item shuttle propulsion uses pose resets, not motor/contact dynamics;
  \item headway is a software center-distance check, not certified block protection;
  \item KUKA, St\"aubli, HC10, and HC10DT models intentionally lack collision geometry;
  \item industrial grippers articulate visually and do not grasp/attach physics payloads;
  \item removable obstacle markers and several payload/device assets are visual-only;
  \item asynchronous Gazebo service failure can leave logical/visual divergence;
  \item learned position/load facts are probabilistic and are accepted only through
        a specific guarded V4 contract; and
  \item direct typed ROS topics can bypass high-level planning/supervision.
\end{itemize}

\section{Third-Party and Redistribution Boundary}

The description install includes imported KUKA, St\"aubli, Motoman, TIAGo,
SCHUNK, Zimmer, and other model/CAD material under Apache-2.0, BSD, and CC
BY-ND terms. \file{mfja_3rd_floor_description/THIRD_PARTY.md} is the current
provenance record. Before external redistribution, add exact upstream license
texts under a maintained \file{LICENSES/} directory and have the intended
distribution reviewed. Preserve attribution when converting or optimizing an
asset; do not overwrite the upstream original silently.

\section{What Must Accompany a Handover}

The receiving maintainer needs more than this PDF:

\begin{itemize}
  \item repository URL, branch, exact commit, intentional unmerged changes, and
        release/tag policy;
  \item supported host/ROS/Gazebo versions and a reproducible four-package build;
  \item current test evidence with commands, exclusions, environment, and logs;
  \item inventory/location/owner/backup policy for datasets, GGUF files,
        checkpoints, promoted bundles, authorizations, and sealed evidence;
  \item independent expected hashes and the prior complete rollback bundle;
  \item known hardware/GPU/display constraints and any host-local configuration;
  \item third-party attribution/license material and redistribution decision;
  \item operational ownership/contact escalation and data-retention policy; and
  \item open issues mapped to the known-gap register above.
\end{itemize}

Secrets, credentials, or private artifact URLs must be transferred through an
approved secure channel, not embedded into YAML, this PDF, shell history, or
Git.

\section{Release/Handover Acceptance Checklist}

\begin{procedurebox}[Technical acceptance]
\begin{itemize}
  \item[$\square$] The checked-out commit and intentional worktree changes are recorded.
  \item[$\square$] A clean dependency check and four-package build succeed on the supported host.
  \item[$\square$] Interfaces, package prefixes, executable/config install surface, and launch arguments match this manual.
  \item[$\square$] Focused tests, registered tests, nine source-only cases, and relevant optional tests have results or explicit exclusions.
  \item[$\square$] Headless Room 315 smoke passes; full-floor/isolated/GUI checks pass where affected.
  \item[$\square$] Rail add, ON/OFF, delayed devices, sensors, headway, target arrival, and fault behavior are verified for the changed surface.
  \item[$\square$] External artifact locations, exact hashes, provenance, and backups are verified independently.
  \item[$\square$] V4 shadow/readiness/acceptance/fault evidence corresponds to the exact candidate; execution has separate authorization.
  \item[$\square$] Rollback to the previous complete bundle has been rehearsed.
  \item[$\square$] No build output, cache, local dataset, virtual environment, model, credential, or unintended ignored file is staged/installed.
  \item[$\square$] Third-party provenance and exact license obligations are complete for the intended distribution.
  \item[$\square$] The Repository Source Index and PDF validation succeed, and the final PDF was visually inspected.
  \item[$\square$] Known limitations, unverified claims, owners, and next actions are signed off by sender and receiver.
\end{itemize}
\end{procedurebox}

\section{Recommended First Maintenance Milestone}

Before adding another research feature, the highest-value stabilization work is:

\begin{enumerate}
  \item make active artifact paths host-portable without weakening hash identity;
  \item fix package-share lookup and prove a copied install;
  \item register or explicitly schedule all source tests and add clean CI;
  \item restrict directory install rules to tracked intended files;
  \item complete third-party license texts for the planned distribution; and
  \item split public executables from import-only modules and begin tested
        extraction of the largest integration hot spots.
\end{enumerate}

These actions reduce handover risk while preserving the existing runtime
contract. Feature work can then proceed against a reproducible baseline.
