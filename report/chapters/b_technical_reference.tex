\section{Visual-model lineage}

The predecessor V3 grouped split contained 1,528 training scenes and 256 scenes
each for Validation and the consumed historical Test. The V3
Validation-selected backbone initialised V4, but neither historical evaluation
partition enters V4. The active V4 output contains, for each of eight known
identities, 14 segment scores, two loaded-state scores, four normalised box
values and one within-segment ratio: \(8(14+2+4+1)=168\) learned values. A
derived 200-value adapter is diagnostic only. The selected optimisation,
sampling and evaluation controls now appear beside their rationale in
\cref{tab:v4-training-controls}; online and offline thresholds are distinguished
in \cref{tab:visual-threshold-map}.
