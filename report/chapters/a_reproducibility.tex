\section{Software environment and handover}

The reproducibility package identifies the final implementation and the records
used for its evaluation. The handover includes an archived or committed copy
of the exact source, together with the current configuration and report bundle
\citep{mfjarepository}. The integrated campaign is retained in two layers: its
lightweight records are versioned with the report, and its complete raw bundle
is published as a checksum-identified release asset. The summary, file manifest
and full-archive checksum list identify the workflow reported in
\cref{chap:results}.

The reference environment is Ubuntu~24.04, ROS~2 Jazzy, Gazebo Harmonic and
Python~3.12. Manifests and hashes provide stable identifiers for generated data
and model results. The report sources and lightweight evidence are versioned
under \path{report/} in the software repository and are also included in the
submission bundle.

The workspace can be identified and built from its root with:

\begin{lstlisting}[language=bash]
source /opt/ros/jazzy/setup.bash
git -C src/mfja_3rd_floor_gz rev-parse HEAD
colcon build --symlink-install --base-paths src/mfja_3rd_floor_gz
source install/setup.bash
\end{lstlisting}

\paragraph{Source and report checks.}

The current source identity and test inventory can be recorded from the
repository root with:

\begin{lstlisting}[language=bash]
git rev-parse HEAD
git status --short
python3 -m pytest --collect-only -q \
  mfja_robot_control_config/test \
  mfja_3rd_floor_description/test
\end{lstlisting}

A reproducible handover records this output and archives or commits the same
source. Test collection confirms discovery, while the executed results are
presented in \cref{chap:results}. From \path{report/}, \code{make check} builds
the PDF, rejects unresolved references or citations and reports the page size
and count. Its diagnostics are preserved as
\path{report/evidence/final_report_build_2026-08-08.log}.

User-facing launch profiles and their current arguments are documented in
\path{docs/INSTALLATION.md},
\path{docs/QUICK_START_AND_FEATURE_GUIDE.md} and
\path{docs/ROOM315_LANGUAGE_TO_MOTION_RUNTIME.md}. The browser-based
\path{runbook.html} supplies copy-ready operator workflows and diagnostic
checks. \Cref{app:interfaces} provides a concise index of the corresponding
capabilities and operator interfaces.
