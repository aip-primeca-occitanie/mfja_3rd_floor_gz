\section{Single verification procedure}

For either release, retrieve the assets using its retained README, confirm that
the immutable tag resolves to the commit listed in
\cref{tab:artefact-identities}, compare the downloaded archive with its declared
SHA-256, then extract it and run the included package-wide
\verb|sha256sum --strict -c SHA256SUMS|. For the lightweight repository package,
also compare the two manifest identities in the first table row. Any mismatch
invalidates the provenance chain and the associated result claim. The release
README files retain the platform-specific download, extraction and stateless
replay commands so that those listings need not be duplicated here.

The replay re-evaluates the selected checkpoint but does not reopen the
historical one-shot Final Test or claim bit-identical retraining across arbitrary
hardware. The reference environment for the recorded replay used CUDA~12.8
\citep{cuda} and is documented in
{\def\UrlBreaks{\do\/\do\_}\def\UrlBigBreaks{}\Urlmuskip=0mu\relax%
\path{report/evidence/room315_visual_v4_dataset_release_v1/ENVIRONMENT.md}}.
